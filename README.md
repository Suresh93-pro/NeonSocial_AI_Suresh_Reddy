# NeonSocial AI — Suresh Reddy

Fast AI social-media command center. Human approval is enforced before scheduling/publishing. Demo mode is safe and does not post to real accounts.

## Start on Windows
```powershell
cd "PATH\TO\NeonSocial_AI_Suresh_Reddy"
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python app.py
```
Then open http://127.0.0.1:8000
